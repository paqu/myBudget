# myBudget 💰

A modern personal finance management mobile application built with React Native, Expo, and TypeScript. Track your income, expenses, and budget categories with an intuitive and clean interface.

## 🚀 Features

- **Authentication System**: Secure user registration and login with Firebase Auth
- **Transaction Management**: Add, edit, and delete income/expense transactions
- **Budget Categories**: Track spending across different categories (Health, Fun, Food, Bills, etc.)
- **Monthly Reports**: View detailed budget summaries and category breakdowns
- **Period Navigation**: Browse transactions and reports by month/year
- **Real-time Balance**: Automatic calculation of income, expenses, and remaining balance
- **Responsive Design**: Clean, modern UI optimized for mobile devices

## 🛠️ Tech Stack

- **Frontend**: React Native with Expo
- **Language**: TypeScript
- **State Management**: Redux Toolkit
- **Authentication**: Firebase Auth (prototype)
- **Navigation**: React Navigation (Stack & Bottom Tabs)
- **UI Components**: React Native Elements, Expo Vector Icons
- **Storage**: AsyncStorage for local data persistence
- **Development**: ESLint, Prettier for code quality

## 📋 Prerequisites

Before you begin, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (v16 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- [Android Studio](https://developer.android.com/studio) (for Android development)
- [Xcode](https://developer.apple.com/xcode/) (for iOS development, macOS only)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/paqu/mybudget.git
cd mybudget
```

### 2. Install dependencies

```bash
npm install
# or
yarn install
```

### 3. Run
```bash
expo start
# or
npx expo star
```
